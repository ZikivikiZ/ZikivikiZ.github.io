## 怎么写下一篇

在 `_posts/` 目录里新建一个文件，名字必须是 `年-月-日-标题.md`，例如：

```
_posts/2026-11-23-今天修了电脑.md
```

文件开头要有一段"头信息"：

```markdown
---
title: 今天修了电脑
date: 2026-11-23 20:30:00 +0800
categories: 折腾
---
```

下面直接写正文，用 Markdown 语法：`#` 是标题，`**粗体**`，`-` 是列表，``` 包代码。

## 在网页上直接写

打开仓库 → 进入 `_posts` → 右上角 `Add file` → `Create new file` → 按上面的格式写 → 提交。
GitHub 会自动编译，一两分钟后刷新页面就能看到。
